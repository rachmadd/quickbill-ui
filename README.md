# quickbill-ui

> [!NOTE]
> **Project status:** This library was originally built for Quickbill. The Quickbill team has archived it and no longer maintains it. It is now an independent project, maintained by [@rachmadd](https://github.com/rachmadd). It is not affiliated with, endorsed by, or supported by Quickbill.

React UI library that extends shadcn/ui with Quickbill design tokens.

Install:

```bash
npm install quickbill-ui
```

See Storybook for more documentation and guidelines.

**[Preview Storybook](https://main--6ace544728e8e596ac5d731e.chromatic.com)**

To run:

```bash
bun install
```

```bash
bun storybook
```
