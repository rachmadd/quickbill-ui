### Usage

Import `Icon` and pass a `name` from the available icon keys. Use `size` to control dimensions and `className` to apply a Tailwind color.

```tsx
import { Icon } from 'quickbill-ui'

// Basic
<Icon name="HomeOutlined" />

// Custom size
<Icon name="SearchOutlined" className="size-6" />

// Colored via Tailwind
<Icon name="CheckCircleOutlined" className="text-qb-success-main" />

// Destructive action
<Icon name="TrashOutlined" size={20} className="text-qb-negative-main" />
```
